# The Agentic Trust Threshold

A research manuscript exploring the concept of an **agentic trust threshold** and its implications for AI-assisted systems.

## Repository contents

- `THE AGENTIC TRUST THRESHOLD.pages` — source manuscript (Apple Pages format)
- `docs/` — GitHub Pages website for web presentation
- `.github/workflows/deploy-pages.yml` — automatic deployment workflow
- `CITATION.cff` — citation metadata

## Read online

## Suggested publishing workflow

1. Keep the `.pages` file as the editable source.
2. Export a PDF from Pages and commit it as `paper/the-agentic-trust-threshold.pdf` (recommended).
3. Update `docs/index.html` with abstract and final citation details.
